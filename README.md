# anthropic-proxy

HTTP-посредник к Anthropic Messages API. Передаёт запрос и возвращает статус и JSON провайдера.

Node.js, Express, node-fetch. Точка входа `index.js`. В коде нет базы и постоянного диска.

В отслеживаемых файлах не найден автоматический набор тестов или GitHub Actions. Локальный запуск описан в [DEPLOYMENT.md](DEPLOYMENT.md).
