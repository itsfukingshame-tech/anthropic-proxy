# Архитектура anthropic-proxy

Node.js, Express, node-fetch. Точка входа `index.js`. В коде нет базы и постоянного диска.

Anthropic Messages API, клиентский заголовок `x-proxy-secret`, серверный `ANTHROPIC_API_KEY`.

## Настройки из исходников

`ANTHROPIC_API_KEY`, `PORT`, `PROXY_SECRET`. Список отражает найденные обращения в коде.

## Риски и технический долг

В коде предусмотрен фиксированный пароль по умолчанию. При отсутствии переменной он позволит доступ к платному API. Лимит тела 10 МБ есть, ограничения частоты и явного таймаута запроса в коде нет.

В Git нет lock-файла зависимостей JavaScript. Установка по диапазонам версий может дать другой результат.

В отслеживаемых файлах не найден автоматический набор тестов или GitHub Actions.
