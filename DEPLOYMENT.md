# Публикация и локальный запуск

`npm start` → `index.js`. Активное размещение этого GitHub-репозитория неизвестно. KEM AI Proxy в Railway — образ `function-bun`, без привязки к этому репозиторию.

## Проверка перед публикацией

1. Зафиксировать целевые репозиторий, ветку, коммит, платформу и команды сборки.
2. Собрать в изоляции, использовать только тестовые учётные данные. Проверить основные страницы, API и отказ при неавторизованном запросе.
3. Перед изменением схемы или формата файлов проверить свежую внешнюю копию. Получить разрешение на публикацию.
4. После разрешённого выпуска проверить состояние сервиса и записать идентификатор релиза и коммит. При проблеме вернуть предыдущий выпуск. Если схема несовместима, остановить запись и отдельно согласовать восстановление.

## Метаданные рабочего окружения

Имена переменных из кода приведены в ARCHITECTURE.md. Привязка к рабочей платформе требует подтверждения.

## Локальное окружение

Установить зависимости и запустить npm start с новым тестовым PROXY_SECRET, без рабочего ключа. Проверить отказ без заголовка x-proxy-secret. Для позитивного сценария требуется подмена провайдера в тестовой среде.

Проверка 25 ноября 2026 года. POST /v1/messages без ключа вернул ожидаемый 403. Проксирование с реальным ключом не проверялось.
