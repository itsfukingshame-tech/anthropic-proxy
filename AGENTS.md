# Инструкции для агента

Работай по-русски. Перед правками прочитай README, ARCHITECTURE, DEPLOYMENT, BACKUP, TASKS и DECISIONS. Начинай с состояния Git, границ задачи и определения затронутого окружения.

- Тестируй в изоляции с тестовыми секретами, данными и подменой внешних интеграций.
- Запрашивай разрешение на доступ к рабочей БД, публикацию, изменение инфраструктуры, удаление данных, откат рабочей среды и отправку в основную ветку.
- Храни секреты в защищённом хранилище. В документации указывай только имена переменных.
- После задачи выполни проверки, обнови документацию и CHANGELOG, укажи статус копий, порядок отката и коротко отчитайся по-русски.
- Проверка для этого проекта. В отслеживаемых файлах не найден автоматический набор тестов или GitHub Actions.

## Общие правила инфраструктуры

Перед работой открой [infrastructure-management](https://github.com/itsfukingshame-tech/infrastructure-management), прочитай AGENTS.md и относящиеся к задаче реестры. При недоступности центра используй правила этого файла и зафиксируй ограничение. После восстановления доступа сверь правила и перенеси ожидающие обновления.

Фиксируй значимые изменения в CHANGELOG.md и технические решения с обоснованием в DECISIONS.md. При изменении инфраструктуры обновляй соответствующие записи центра отдельным PR. Сначала проверяй статус копии и согласованный способ отката, затем тестируй и записывай результаты.
